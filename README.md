# BeerZdec - Система управления пивоваренным производством

Система для управления полным циклом пивоваренного производства: от выращивания зерна и солода до варки пива и продаж.

##  Возможности

- **Агрономия**: управление посевами, уборкой урожая, хранением зерна
- **Солодовня**: контроль процессов солодоращения, оборудование, заказы
- **Сырьё**: учёт поставщиков, закупленного сырья, складских ячеек
- **Пивоварня**: журналы варок, рецептуры, стили пива
- **Продажи**: работа с заказами, розничными магазинами и оптовыми клиентами
- **Разграничение прав доступа**: ролевая модель (Admin, Agronomist, Malter, CrudeManager, Brewer, SalesManager)

## 🚀 Быстрый старт с Docker

### Требования

- **Docker Desktop** (для Windows/Mac/Linux)
- **.NET 8.0 Runtime** (уже включён в опубликованную версию)

### Установка и запуск

#### 1. Установите Docker Desktop

Скачайте и установите с официального сайта: https://www.docker.com/products/docker-desktop/

После установки убедитесь, что Docker запущен (в трее должен быть значок 🐳).

#### 2. Запустите базу данных в Docker

Откройте терминал в папке с проектом и выполните:

```bash
# Остановить и удалить старые контейнеры (если есть)
docker-compose down -v

# Запустить SQL Server в контейнере
docker-compose up -d
