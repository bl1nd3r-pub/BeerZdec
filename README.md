# BeerZdec (WIP)

## Краткая информация
BeerZdec - курсовой проект по дисциплине "Разработка, администрирование и защита баз данных" по теме "Пивоварение"
Включает в себя функционал, помогающий регулировать и администрировать(?) выращивание пшеницы, солода и пр. и полный цикл производства от сырья до готовой продукции с реализацией под заказ и в сети фирменных магазинов
